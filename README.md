# ai_data_guardian_lite Flow

This project defines a declarative CrewAI Flow in `src/ai_data_guardian_lite/flow.yaml`.

## Install

```bash
crewai install
```

## Run

```bash
crewai run
```

Edit the declarative flow definition at `src/ai_data_guardian_lite/flow.yaml` to change the flow. Add reusable crews under `src/ai_data_guardian_lite/crews/`, custom Python tools under `src/ai_data_guardian_lite/tools/`, and shared knowledge files under `src/ai_data_guardian_lite/knowledge/`.
